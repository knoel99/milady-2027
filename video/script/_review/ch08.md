   - "Divergence-free" was never defined in narration in ch00-ch07 (grep). 01.2 only planted the box ("as many lines go in as come out").
   - s1 now reads "Every training field passes the box test: it is divergence-free." This matches the visual, where the chalk box appears on the reference map at `clean`.

   - To pay for the new words, "and nothing else" was cut from s2. The word "plain" and the label "no constraint" carry that meaning.
2. **08.3.s1 and s2: the hill-map physics.**
   - The old text said "Water on contour lines never piles up or leaks". Flow along contour lines is divergence-free only if its speed is set by the contour spacing: u = ∇⊥ψ, so |u| = |∇ψ| (R:327-336). Real water also runs downhill, not along contours.
   - The new text says "…let the flow run along its contour lines. Where the lines crowd, it runs faster, so nothing piles up or leaks…".
   - A label "faster where the lines crowd" was added. The visual now asks for the tracer speed contrast to stay legible, with no speed normalisation.
3. **08.4.s3: a physics error ("the wind must pull ever harder").**
   - On the ideal path y = (1 − t)y₀ the pull is constant: dy/dt = −y₀. Only the stiffness, the rate 1/(1 − t), blows up (Proposition 2 (a), (d); pedagogy K12: "squeezes at a rate 1/(1 − t)").
   - The new text says "…must act as a spring that turns infinitely stiff as the transport clock runs out."
   - A visual note forbids a growing force arrow.
4. **08.4.s1 and s5.**
