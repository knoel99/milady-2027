## Notes on departures

- **2D rather than 3D (S7)**: the mission window (90 min), the CPU-only budget choice and the need for
  a statistically meaningful ensemble (>=128 held-out fields) made a 3D spectral MHD dataset
  infeasible. The method and code are dimension-agnostic; the report states this limit explicitly.
- **Helicity (S6)**: in 2D, `b = curl(A z)` has no magnetic helicity; the rugged invariant
  `<A^2>` is the correct 2D analogue and is used. This is a deliberate, justified substitution,
  not a silent omission.
- **Toolbox integration (S10)**: the MilaDy toolbox is not part of the mission workspace; the
  deliverable is a self-contained package with a stable API and a one-command reproduction script.
