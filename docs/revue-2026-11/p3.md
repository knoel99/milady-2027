# P3 — relecteur-physicien (Fable)

Énoncés, preuves et corrigés refaits à la main : justes hors constats. Chiffres E1 conformes au digest. Sources ouvertes : Tobias arXiv:1907.03685, Rincon arXiv:1903.07829.

## Bloquant
1. §7.2 l.1324 (légende l.1326) : « aucun attracteur simple, d'où le chaos » faux (pour 0,138 < μ < 0,2, cycle limite, dynamo.md §2.4) ; chaos non mesuré pour Γ ≤ 0,86. Seul chaos publié : Γ = 0,9, μ = 0,119 (Lyapunov ≃ 0,1, Gissinger 2012). Réécrire ou ajouter un exposant de Lyapunov au code.

## Important
2. Rincon 2019 et Faranda 2014 absents de specs/sources (chiffres et numéros d'équation attribués) ; partiellement vérifiés à la source ; nombreux chiffres non vérifiés (noyau terrestre, Rm solaire, Rm = 514, éq. 4.23, 4.85, durées entre renversements, Faranda tableau 1). 4. §5.5 l.1125, §6.3 l.1165, récap l.1140 : VKS : 31 vient de l'ajustement linéaire de B ; celui de ⟨B²⟩ donne ≈ 35 ; Monchaux 2009 : exposant 0,77.

6. Notions du module 4 (Hopf, Floquet, fourche, sous-critique, hystérésis, nœud-col, attracteur, crise, doublements) utilisées avant P4 (ordre 1, 2, 5, 3, 4) : définir sur place.
7. Ch. 4 : harmoniques sphériques, Bessel sphériques, coordonnées sphériques jamais introduits (P1 n'a que les cylindriques) ; Frenet, Grönwall, résidus aussi. Encadré de rappel ou prérequis.
8. Récap ch. 7 l.1368 : « aucun renversement pour Γ ≤ 0,86 » = 4 trajectoires de 4500, une graine ; écrire « aucun observé sur 18 000 unités ».
9. Objectif 4 l.48 : modes libres « pour chacune » alors que trois conditions sur quatre sont traitées.
10. Prop. 4.3 : en conducteur parfait, le mode toroïdal l = 1 (kR ≈ 2,744) décroît plus lentement que le poloïdal ; préciser « poloïdal ».
