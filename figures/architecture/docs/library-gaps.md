# Pièces dessinées faute de pièce de bibliothèque

- `sheet` (feuille à coin plié) : aucun glyphe « document » dans lib.js ni cs.js.
- `dbGlyph` (cylindre de base de données) et `folderGlyph` (dossier) : pas de glyphes de rôle « stockage » dans cs.js.
- `laptop`, `server`, `cloud` + `server` : icônes de machines construites sur `L.obliqueBox` et `L.cloud`.
- `paramGrid` : grille de points de paramètres réutilisée dans trois vignettes.
