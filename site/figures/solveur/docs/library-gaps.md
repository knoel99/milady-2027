# Pièces dessinées faute de pièce de bibliothèque

- `modePlane` : plan de modes de Fourier avec coupure de désaliasage (aucun glyphe spectral dans lib.js ou cs.js).
- glyphe de projection de Leray (décomposition d'un vecteur selon k), construit avec `L.arrow`.
- frise de simulation (`timeline`) : barres d'exécution, losanges de points de contrôle, éclair (`L.bolt`), peigne de diagnostics.
- correspondance arbre HDF5 ↔ tables (`mapping`).
