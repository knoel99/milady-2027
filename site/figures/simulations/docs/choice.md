# Choix entre les deux brouillons

Rendus : `figure/out/simulations_a.png` (une rangée par expérience) et `figure/out/simulations_b.png` (une colonne par expérience).

- **A** : graphes de balayage plus larges (46 mm) ; texte groupé par colonne ; à corriger : échelle de λ écrasée par λ(2) = −0,50 (les fenêtres de dynamo ne se voient pas), points verts d'E3 présentés comme « entraînement » alors qu'E3 n'entraîne aucun modèle.
- **B** : lien visuel fort avec plan-these (vignettes en tête), mais bandes vides entre les rangées « Balayage », « Schéma », « Données », graphes plus étroits (38 mm), mêmes défauts d'E3.

**Choix : A** (moins de vide, graphes plus lisibles) ; les deux défauts d'E3 sont corrigés (axe restreint à ±0,012 avec les trois points hors échelle marqués d'une flèche ; points verts retirés pour E3).
